# Text-to-Video Generator

Generate short videos from any text description using the `damo-vilab/text-to-video-ms-1.7b` diffusion model.

## Usage

1. Enter a prompt describing your video
2. (Optional) Add a negative prompt for things to avoid
3. Adjust frames, steps, and guidance scale
4. Click **Generate Video**
